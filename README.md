**Entry:**

> I taught my cat to high-five, and now she uses it exclusively to slap treats out of my hand before I can change my mind.

## Run

```sh
python3 main.py
```

Prints the entry and writes it to `/output/entry.txt` (the harness artifact
for this competition). The line was chosen from 12 candidates duel-scored
against the competition's published judge brief — see `candidates.md`.
